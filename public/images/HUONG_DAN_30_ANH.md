# 📸 Hướng dẫn đặt 30 ảnh cho Website Thiệp cưới

Toàn bộ ảnh bạn chỉ cần lưu vào thư mục này:
👉 **`public/images/`**

Hệ thống đã được lập trình **tự động nhận diện**:
- Hỗ trợ các định dạng: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif` (kể cả viết hoa `.JPG`, `.PNG`).
- **Không cần sửa code**: Cứ lưu đúng tên file vào thư mục `public/images/`, tải lại trang web là ảnh thật sẽ tự động hiển thị!
- Trên màn hình website `http://localhost:3000`, mỗi vị trí ảnh đều hiển thị sẵn huy hiệu `📁 public/images/...` để bạn đối chiếu trực quan.
